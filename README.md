# Community Health Intelligence

เว็บไซต์บันทึกและจัดการข้อมูลชุมชน 7 เครื่องมือ พร้อมแบบสำรวจข้อมูลพื้นฐาน ใช้ Google Apps Script เป็น API และ Google Sheets เป็นที่เก็บข้อมูล

## ฟีเจอร์แผนที่และความสัมพันธ์

- แผนที่: เริ่มต้นซูมบริเวณตำบลเก่างิ้ว อำเภอพล จังหวัดขอนแก่น กด **ปักหมุดจากแผนที่** แล้วคลิกตำแหน่งครัวเรือนเพื่อเติมพิกัดในแบบฟอร์ม สัญลักษณ์ `*` แทนเบาหวาน และมีสัญลักษณ์เฉพาะสำหรับความดันโลหิตสูง โรคหัวใจ โรคไต และมะเร็ง บันทึกครัวเรือนได้หลายรายการต่อเนื่องด้วยปุ่ม **บันทึกและเพิ่มครัวเรือนต่อ** โดยระบบไม่จำกัดจำนวนรายการ
- แบบสำรวจข้อมูลพื้นฐาน: บันทึกรหัสบ้าน ชื่อครอบครัว และเลขประจำตัวหัวหน้าครอบครัว พร้อมเพิ่มสมาชิกได้หลายคนในครัวเรือนเดียว ครอบคลุมข้อมูลบัตรประชาชน ชื่อ วันเกิด เพศ อายุ สถานภาพสมรส อาชีพ สถานะในบ้าน การศึกษา การวางแผนครอบครัว สิทธิรักษาพยาบาล โรค/ความพิการ และการย้ายเข้า/ออก แต่ละรายการครัวเรือนจัดเก็บในชีต `survey`
- ปฏิทินชุมชนแสดงสรุปกิจกรรมเป็นตารางแยกตาม 12 เดือน พร้อมตารางรายละเอียดกิจกรรมที่ใช้แก้ไขและลบรายการได้ กิจกรรมที่ระบุเป็นฤดูกาลหรือไม่ระบุเดือนจะแสดงในกลุ่มช่วงเวลาอื่น
- แผนที่ขยายเต็มหน้าจอได้จากปุ่ม **ขยายแผนที่** และซูมเข้าได้ถึงระดับ 25 (ภาพถ่ายดาวเทียมต้นทางอาจมีรายละเอียดสูงสุดที่ระดับ 19 การซูมต่อจากนั้นเป็นการขยายภาพและอาจไม่คมชัดขึ้น)
- ผังเครือญาติ: เพิ่มครัวเรือนจากหน้าผังได้ต่อเนื่องด้วย **บันทึกและเพิ่มครัวเรือนต่อ** แล้วเลือกครัวเรือนก่อนเพิ่มสมาชิก ผังเลือกดูแยกตามครัวเรือนได้ สมาชิกเดิมที่ยังไม่ผูกครัวเรือนจะแสดงในตัวเลือกแยกต่างหาก เลือกคู่สมรสและบิดา/มารดาจากสมาชิกที่มีอยู่เพื่อเชื่อมเส้นความสัมพันธ์ พร้อมแสดงพี่น้องเมื่อระบุพ่อแม่ร่วมกัน และเลือก **บุคคลหลัก** เพื่อแสดงสัญลักษณ์เพศแบบทึบ
- โครงสร้างองค์กรชุมชน: เลือกหัวหน้าหรือองค์กรต้นสังกัดในช่อง **ขึ้นตรงกับ / หัวหน้า / องค์กรแม่** เพื่อแสดง mapping ความสัมพันธ์จากบนลงล่าง ตารางรายการเดิมยังคงอยู่ และป้องกันการเลือกผู้ใต้บังคับบัญชาเป็นหัวหน้าเพื่อหลีกเลี่ยงวงจร
- ประวัติบุคคลสำคัญ: Timeline เรียงตามปีเกิดและปีของเหตุการณ์ ใช้รูปแบบ `ปี | เหตุการณ์ | รายละเอียด` หนึ่งเหตุการณ์ต่อบรรทัด รองรับการเรียงปี พ.ศ. และ ค.ศ.

## เผยแพร่หน้าเว็บด้วย GitHub Pages

1. อัปเดตโค้ดใน `Code (5).gs` ใน Apps Script และ Deploy เป็นเวอร์ชันใหม่ เพื่อเปิดใช้ชีต `survey` แล้ว push ไฟล์นี้และ `index.html` ไปยัง branch `main` ของ repository
2. ใน GitHub เปิด **Settings → Pages** และเลือก **GitHub Actions** เป็นแหล่งเผยแพร่ หาก workflow ยังไม่เปิด Pages ให้อัตโนมัติ
3. รอ workflow **Deploy static site to GitHub Pages** ให้สำเร็จ เว็บไซต์จะอยู่ที่ `https://maryj3lly.github.io/KAO-NGIO-COMMUNITY-HEALTH-INTELLIGENCE/`

## ตั้งค่า API และรหัสผู้ดูแลก่อนใช้งาน

1. เปิด Apps Script project ที่เป็นเจ้าของ URL `/exec` ซึ่งกำหนดไว้ใน `index.html` อย่าเผยแพร่หน้าเว็บก่อนเปลี่ยนรหัสผ่านเริ่มต้นของ API ที่ใช้อยู่
2. ใน Apps Script ให้รัน `changeAdminPassword()` และดูรหัสผ่านสุ่มใน execution log จากนั้นเก็บไว้ในที่ปลอดภัย รหัสผ่านนี้จะไม่แสดงในเว็บไซต์หรือใน repository
3. เผยแพร่ Apps Script เป็น Web app ที่ทำงานในนามเจ้าของและอนุญาตการเข้าถึงตามนโยบายของโครงการ แล้วอัปเดต URL `/exec` ใน `index.html` หาก URL เปลี่ยน
4. เข้าสู่ระบบด้วยชื่อผู้ใช้ `admin` และรหัสผ่านที่เพิ่งสร้าง หากเป็น Apps Script project ใหม่ ให้รัน `setupSystem()` ก่อน และเก็บรหัสผ่านเริ่มต้นที่แสดงใน execution log

ข้อมูลสุขภาพ เลขประจำตัวประชาชน และตำแหน่งครัวเรือนเป็นข้อมูลอ่อนไหว ควรเก็บเท่าที่จำเป็น แจ้งวัตถุประสงค์และขอความยินยอม จำกัดผู้มีสิทธิ์เข้าถึง และปฏิบัติตามนโยบายคุ้มครองข้อมูลของหน่วยงาน
